# Web3 Agent Lab 中文用户手册

## 打开本地实验室

需要 macOS 或可运行 Anvil 的环境、Python 3.10+、Node.js 22+ 和 npm。在仓库根目录执行：

```sh
python3 -m src.lab
```

在浏览器打开终端显示的地址，默认是 127.0.0.1:8765。已有档案可直接阅读，无须启动交易链或安装 npm 包。端口占用时用 `--port 0` 自动选择。终端按 Control+C 关闭界面服务。HTML、脚本、图表和证据都由本机提供。

## 第一次用 10 分钟看懂一笔交易

首页「市场实验总览」先显示已完成的轮次、链上成交、风控拒单和模型费用。「看回执与前后余额」直达一笔示例，「回放这组实验」打开长程基准。

1. 在首页点击「看回执与前后余额」，打开 E000067。
2. 在「交易与区块浏览器」看哈希、区块和 Gas。背景角色交出 18 RISK，钱包的 sUSD 增加约 17.913852。池子中两种资产的变化与钱包相反。
3. 在「合约事件 Logs」找到两条 Transfer 和一条 Swap。前两条是代币合约的账，第三条记录池子成交。展开原始 JSON 可查看十六进制回执。
4. 点击关联风控和决策，分别找「为什么能提交」与「角色为什么想卖」。用哈希搜索可回到同一笔交易。
5. 打开 [AMM 数学实验](/#lab-amm)，预测到账再输入 10,000 / 10,000 / 18。将结果与真实回执对照。
6. 想了解上下文，读 [100 轮新手故事](/artifact/first-100/story.md)。想按周学习，打开 [课程](/#course)。

## 回放与比较

- 「实验」下拉选择档案。「上一轮」「前进一轮」「播放」与滑块共同控制图表、持仓和净值。在末轮按「播放」从开头重播。
- 绿红蜡烛展示该轮成交价 OHLC，灰蓝虚线展示合成参考价。成交量单位为 RISK，标记 ▲/▼ 表示买／卖，◆ 表示新闻。角色筛选只过滤买卖标记，K 线与成交量仍显示全市场。
- 点击 K 线或空轮区域，跳到该轮并列出所有决策。点击新闻或买卖点跳到具体证据。「部署与注资」跳到第 0 轮；「查看集成测试回退」打开一条独立测试链的回退。
- 展开「实验并排对照」，选择另一个档案并比较轮数、成交、期末净值和回撤。若时间长度、资金或种子不同，先核对配置再解释差异。
- 键盘可切换图表轮次、标记与按钮。较窄屏幕可水平滚动图表和表格。

## 在本机执行实验

```sh
./scripts/doctor.sh
npm ci
npm run compile
python3 -m src.run --rounds 1000 --run-id my-1000 --seed 7631 --order rotate
python3 -m src.archive data/experiments/my-1000
```

轮数支持 1–10,000，100、500、1000、5000 均在范围内。新 ID 不能覆盖旧档案。Anvil 进程为每次运行分配独立本地端口与测试账户。配置深度、单笔上限、模型预算时以仓库样例为起点。档案输出到 data/experiments，可刷新页面后选择。超过 100 轮默认只保留原始 JSONL、索引所需派生数据和双报告；新版 UI 按轮取证。

终端和 status.json 记录进度。Control+C 或 SIGTERM 请求在完整轮次收盘后停止。检查点记载轮次、钱包、储备和 JSONL 字节位置。封存成功后可重建已停止实验：

```sh
python3 -m src.run --rounds 20 --run-id stop-demo --stop-after 5 --compact
python3 -m src.run --rounds 20 --run-id rebuild-demo --restart-from stop-demo --compact
```

重建会启动新链，从第 1 轮重演，校验父档案的确定性前缀后继续。父链的哈希和区块历史仍留在父档案。异常断电或 RPC 失败若未得到封存状态，应保留原档并重新用新 ID 运行。状态文件会区分 running、exporting、complete、stopped 与 failed。

## 模型和费用

基准模式是 mock-v1，背景和套利是规则策略。离线替身 fixture-v1 可验证接口与预算，费用为零。

```sh
python3 -m src.run --rounds 5 --run-id my-fixture --models configs/models.fixture.json
```

真实模式需要另外配置经授权的回环中继、精确的模型 ID 和显式运行开关。项目默认不请求模型。所有档案的开发 ETH Gas、池内代币费用和记录的 API 成本分别报告。

## 常见问题

- 浏览器打不开。检查终端服务是否仍运行，浏览器打开实际打印的端口，确认地址为 127.0.0.1。
- 刚生成的档案看不到。刷新页面。若运行中断，检查 status.json、Anvil 日志与最后一条 JSONL；成功结算的回执仍可从事件查找。
- 使用 5000 轮专门档案目录。运行和界面使用相同的 `--archive-root`。默认档案目录不受影响。
- 找不到链上哈希。检查它是风控拒单、归档链上回退，还是来自另一个实验。临时链退出后从归档查证。
- 命令提示 Anvil 缺失。运行 npm ci，或以 ANVIL_BIN 指向本机 Anvil。
