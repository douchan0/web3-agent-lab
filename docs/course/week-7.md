## 概念与可复算示例

Agent 接收状态并返回决策，模型只是其中一种实现。mock-v1 是三个主策略的程序化实现。fixture-v1 是离线协议替身。真实模型版本由中继发现并记录。角色只收到该轮可见消息、公开行情和自己的持仓，返回七项结构化字段和简短公开理由。

每角色最多请求 3 次且共跑 5 轮时，前三轮可请求，其余回退。三个角色有独立上限，所以最多 9 次协议调用。离线替身没有模型 token 和 API 费用。真实费用依赖中继或提供方用量。

## 理解题与参考答案

1. 没有私有推理还能审计吗？ 答。可以审计公开输入、摘要、订单与回执。
2. 模型 A 用趋势、B 用逆向能归因到模型吗？ 答。角色也改变，需固定角色。
3. 超时后为什么停止该角色的进一步模型请求？ 答。原请求可能已经收费，自动重试会扩大不确定性。

常见误解。把 Agent 等同于真实 LLM。应核对 mode、模型 ID 和用量。
