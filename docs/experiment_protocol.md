# 实验协议

- 固定种子、虚拟 UTC 起点、每轮时长、初始资金、池储备、样例包和执行次序。深池和浅池分别归档，浅池按储备比例降低初始资金并保持单笔实验名义尺寸，便于观察深度差异。
- 一条新闻必须同时满足发表时间与可见时间不晚于当轮时刻。新闻方向仅驱动样例参考序列和公开事件策略，参考价与链上储备比各自记录。
- 三个 mock 角色和背景交易者先在同一轮开盘快照下生成意图，再依序风控、成交。最后的套利角色以实时储备比和外部参考价决定方向。按角色固定隔离资金、输入和地址。
- 报表以每轮首次真实成交为开盘价，最后一笔为收盘价，最高最低从当轮所有成功兑换的 sUSD/RISK 平均成交价计算。无成交轮保留事件与时间，OHLC 留空。
- 策略净值以同一外部参考价标记，按轮收盘计算回撤。Gas 以本地开发 ETH 独立统计。首轮不把 Gas 或样例资产折算成法币。
- 页面用轮次回放归档事件。重复运行可比较策略意图、成交数量、储备和价格；新 Anvil 的区块时间、哈希及 Gas 需查看各自回执。固定次序会造成执行优先级偏差。角色表现只描述本次实验。
