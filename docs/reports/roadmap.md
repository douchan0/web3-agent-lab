# 下一阶段研究路线图

1. 先验证中继的供应商授权与硬预算，用每角色至多一次的明确授权测试检查具体模型版本、计费和失败码。各模型用同一个角色和可见信息集，单独计入回退。
2. 增加真实历史消息与基准行情导入，保留独立来源和可见时间。对时间泄漏做反向测试，再引入无新闻对照。
3. 扩大配对种子与预注册指标，分别操纵池深度、执行顺序和风控阈值。逐种子报告效应与不确定性。
4. 需要保留原链语义时验证 Anvil 状态快照与交易历史的恢复范围。把真正续跑与当前已验证的换链重建分别归档。
5. 检查长跑中的仓位耗尽、样例信息过期与重复观望。用有效样本与市场活跃度解释长程结果。
6. 邀请初学者实际做一次从预测到回执的练习，记录卡点、计算差错和完成时间，以学习结果优化教程。
